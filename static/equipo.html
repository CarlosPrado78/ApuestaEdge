Por qué existe este proyecto

  • Los pronósticos deportivos están llenos de resultados inventados y capturas de pantalla. Aquí cada pick se publica antes del evento y se asienta con el marcador real.
  • Nadie puede borrar una pérdida ni editar una cuota: el registro es append-only con cadena de hashes SHA-256 anclada a OpenTimestamps.
  • El plan Premium no se lanza hasta tener 200 picks cerrados con CLV calculado y hash anclado. Mientras tanto, lista de espera honesta.
  • Una sola persona, responsable de todo: si el modelo falla, lo verás en el changelog público.
