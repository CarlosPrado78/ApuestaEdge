Buscando el ancla diaria…

La comprobación del navegador verifica el enlace entre filas, el hash de cada fila sobre su contenido canónico y el hash del ancla. El verificador de Python reconstruye además ese contenido canónico desde los campos crudos, para que no dependas de lo que declare esta página.

Verificación independiente en tu máquina

Tres pasos, sin instalar nada más que Python. El script solo usa la biblioteca estándar y no llama a nuestra API: lee el paquete que descargaste.

  1. Descarga el paquete

    Contiene las filas crudas de las tres cadenas, la especificación del hash y todas las anclas publicadas.

    Descargar paquete (JSON)

  2. Descarga el verificador

    Un archivo de Python legible, sin dependencias. Puedes revisarlo antes de ejecutarlo.

    Descargar verificador (Python)

  3. Ejecútalo

    Te dirá fila por fila si la cadena cuadra o dónde se rompió.

    python verify_ledger.py apuestaedge-ledger.json

Qué garantiza

  • Que ninguna fila publicada se editó, borró ni reordenó después.
  • Que la cuota de cierre y el resultado se añadieron como filas nuevas, no reescribiendo el pick.
  • Que el ancla diaria resume las tres cabezas en un único hash comprobable.

Qué no garantiza

  • Que el modelo acierte: la transparencia no elimina la varianza.
  • Habría que comparar el ancla con una copia externa (red social, archivo, testigo) para detectar una reescritura completa y coordinada. El anclaje externo está en el roadmap.
  • Que un resultado sea justo: se asienta con el marcador oficial de la fuente de datos.
